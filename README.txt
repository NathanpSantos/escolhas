PRIMEIRO ENCONTRO 2.0 — LANDING PAGE

1. Abra index.html no navegador para testar.
2. Para publicar no GitHub Pages:
   - Crie um repositório público no GitHub (ex: primeiro-encontro-2-0).
   - Envie o arquivo index.html para a raiz do repositório.
   - Vá em Settings > Pages > Build and deployment > Deploy from a branch.
   - Selecione main e / (root), salve.
   - O endereço geralmente será: https://SEU-USUARIO.github.io/primeiro-encontro-2-0/

Os dois botões abrem uma mensagem pronta no WhatsApp para ela enviar.
O site não grava as respostas, não envia mensagens automaticamente e não exige telefone.
A imagem referencia.png é somente uma referência visual, não é necessária ao site.

Se quiser personalizar textos, edite index.html em um editor de código.
